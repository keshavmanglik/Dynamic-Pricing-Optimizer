Project scope: React-based CSV upload, preview and column mapping, together with Python-based data cleaning, duplicate removal, data-quality checks and descriptive analysis. The current release focuses on preparing and exploring transaction data. A unified analysis service, validated elasticity modelling, competitor-price/promotion inputs and automated price recommendations are planned enhancements. The supplied dataset does not contain an explicit unit selling-price field; Sales_Amount divided by Quantity is only a transaction-value-per-unit proxy.
